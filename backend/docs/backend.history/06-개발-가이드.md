# 06. 개발 가이드

## 1. 요구 환경

- Java 21
- 별도 Gradle 설치 불필요: Wrapper 포함
- 로컬 실행 시 별도 DB 불필요: H2 사용

## 2. 실행

```powershell
cd backend
.\gradlew.bat bootRun
```

- API: `http://localhost:8080/v1`
- Health: `GET http://localhost:8080/v1/health`
- H2 Console: `http://localhost:8080/v1/h2-console`

## 3. 테스트

```powershell
.\gradlew.bat clean test --no-daemon
```

현재 테스트는 Spring Context와 게스트 인증 → 아이 생성 → Refresh Token 회전·재사용 거부 흐름을 검증한다.

## 4. 환경변수

`.env.example` 참고:

```text
SPRING_PROFILES_ACTIVE=prod
DB_URL=jdbc:postgresql://...
DB_USERNAME=...
DB_PASSWORD=...
JWT_SECRET=32-byte-or-longer-random-secret
STORAGE_DIR=/private/uploads
```

## 5. Docker

```powershell
docker build -t booktalk-backend .
docker run --rm -p 8080:8080 -e JWT_SECRET=... booktalk-backend
```

## 6. 새 기능 추가 규칙

1. 컨트롤러는 HTTP 계약만 처리한다.
2. 소유권·상태 전이는 서비스에서 검증한다.
3. 엔티티의 상태 변경은 의미 있는 메서드로 캡슐화한다.
4. 오류는 `BusinessException(ErrorCode)`로 통일한다.
5. 민감한 원문을 로그에 남기지 않는다.
6. 외부 호출은 인터페이스/어댑터 경계로 분리한다.
7. 성공·오류 응답 envelope를 유지한다.
