# 01. 작업 이력

## 1. 기준 브랜치

- 원격 기준: `origin/feat/backend-setup`
- 작업 브랜치: `codex/backend-completion`
- 작업 폴더: `backend-workspace/backend`
- 프론트엔드와 `design-collab` 코드는 수정하지 않았다.

## 2. 기존 작업

1. Spring Boot 4.1.2 및 Java 21 프로젝트 셋업
2. H2 로컬 프로필과 PostgreSQL 운영 프로필 설정
3. JWT Access Token 기반 게스트 인증
4. 사용자 조회·수정 API
5. 아이 프로필 목록·생성·수정 API
6. 도서 목록·상세 및 cursor 페이지네이션
7. multipart 그림책 페이지 업로드
8. 로컬 비공개 파일 저장소
9. 비동기 페이지 분석 작업 생성 및 상태 조회
10. 분석 결과 표현 저장
11. 공통 성공/실패 응답과 Request ID
12. CORS, JPA Auditing, 전역 예외 처리

## 3. 이번 추가 작업

1. Refresh Token 저장·회전·재사용 감지·로그아웃
2. 아이 프로필 삭제 확인 절차
3. signed URL 형태의 2단계 이미지 업로드 계약
4. 페이지 분석 결과 조회 및 작업 취소
5. 표현 상세 조회
6. 아이별 북마크 저장·해제·조회
7. 학습 이벤트 멱등 저장과 진행 상태 갱신
8. 문장 연습 저장 및 규칙 기반 첨삭
9. AI 대화 세션 시작·메시지·종료·조회
10. 복습 항목 생성, 오늘의 복습, 답안 처리
11. 기간별 학습 요약
12. 알림 설정 및 푸시 기기 등록
13. TTS/STT API 계약
14. 분석 취소와 비동기 작업 사이의 경쟁 상태 보호
15. Dockerfile, 환경변수 예시, 백엔드 README
16. 인증·아이 프로필 통합 테스트
