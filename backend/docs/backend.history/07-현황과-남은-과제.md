# 07. 현황과 남은 과제

## 1. 완료

1. 인증과 사용자/아이 기본 흐름
2. 도서 조회와 페이지 업로드
3. 비동기 분석 상태 머신
4. 분석 결과에서 학습 기능으로 이어지는 데이터 흐름
5. 북마크·문장·대화·복습의 MVP 저장 구조
6. 알림 설정과 기기 등록
7. 공통 보안·오류·응답 규칙
8. 로컬 실행 및 Docker 빌드 설정
9. Hybrid RAG, GraphRAG Local/Global, 제한형 PlanRAG
10. evidence citation, confidence, verifier 및 근거 부족 시 abstention

## 2. 외부 연동 필요

1. 실제 OCR/표현 추출/번역 AI
2. RAG의 extractive generator를 실제 LLM provider로 교체
3. 실제 문장 첨삭·대화 모델과 안전 필터
4. 실제 TTS 음원 생성 및 CDN 저장
5. 실제 STT 작업 처리
6. FCM/APNs 푸시 발송
7. Supabase Storage 또는 S3 signed URL

## 3. 운영 기능 미완료

1. 운영자 인증과 MFA
2. 콘텐츠 검수용 Vocabulary 마스터
3. 감사 로그 조회 API
4. 분석 작업 운영자 재시도 API
5. Rate Limit 및 일일 AI quota
6. 예약 삭제 worker와 미디어 retention worker
7. DB migration 체계

## 4. 테스트 보강 필요

1. 업로드 → 분석 → 표현 조회 전체 흐름
2. 북마크 → 문장 → 대화 → 복습 전체 흐름
3. 다른 사용자 리소스 접근 차단
4. 비동기 분석 취소 경쟁 상태
5. PostgreSQL Testcontainers
6. 파일 크기·매직 넘버·sha256 오류 경계값
7. 동시 Refresh Token 재사용

## 5. 알려진 제한

- 로컬 H2는 서버 종료 시 데이터가 사라진다.
- TTS 응답 URL은 공급자 연결 전 계약용 경로다.
- STT는 현재 작업 ID 발급 계약까지만 제공한다.
- 문장 첨삭과 AI 대화는 규칙 기반 로컬 응답이다.
