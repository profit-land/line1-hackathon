# 05. DB 스키마

로컬에서는 H2가, 운영에서는 PostgreSQL이 사용된다. 현재 스키마는 JPA 엔티티를 기준으로 생성된다.

## 1. 계정

| 테이블 | 핵심 컬럼 | 관계 |
|---|---|---|
| `users` | type, device_id_hash, display_name, preferred_language, status | 1:N children |
| `refresh_sessions` | token_hash, expires_at, revoked | N:1 users |
| `children` | nickname, age, relationship, explanation_language | N:1 users |

## 2. 도서와 분석

| 테이블 | 핵심 컬럼 | 관계 |
|---|---|---|
| `books` | source, title, author, min_age, max_age, expression_count | 선택적 owner |
| `book_pages` | page_label, storage_key, sha256, status, ocr_text | book, owner, child |
| `uploads` | content_type, size_bytes, sha256, status, expires_at | N:1 user |
| `analysis_jobs` | status, stage, progress, model, error_code | N:1 page, child |
| `page_expressions` | text, type, definition, translation, source_sentence | N:1 page |

## 3. 학습

| 테이블 | 핵심 컬럼 | 제약 |
|---|---|---|
| `bookmarks` | child, expression, learning_status | child+expression unique |
| `learning_events` | event_id, type, occurred_at | event_id unique |
| `sentence_practices` | original_sentence, suggested_sentence, assessment | child, expression 참조 |
| `reviews` | stage, due_at, last_correct | child+expression unique |

## 4. 대화와 알림

| 테이블 | 핵심 컬럼 | 제약 |
|---|---|---|
| `conversation_sessions` | scene, difficulty, status, turn_count, target_used | child, expression 참조 |
| `conversation_messages` | role, client_message_id, text | session+client_message_id unique |
| `notification_settings` | enabled, channels, reminder_time, timezone | user unique |
| `push_devices` | platform, device_id_hash, push_token_hash | user+device unique |

## 5. ID 접두사

`usr`, `chd`, `bok`, `bpg`, `job`, `exp`, `rfs`, `upl`, `bmk`, `evt`, `spr`, `cvs`, `msg`, `rev`, `dev`를 사용한다.

## 6. 운영 전 필수 변경

현재 운영 프로필은 `ddl-auto: update`이다. 정식 배포 전에는 Flyway 또는 Liquibase migration을 만들고
`ddl-auto: validate`로 변경해야 한다.
