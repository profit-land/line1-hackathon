# API Feature Summary

| 영역 | 기존 구현 | 추가 구현 | 현재 상태 |
|---|---|---|---|
| 인증 | 게스트 Access Token | Refresh 회전, 재사용 감지, 로그아웃 | 동작 |
| 사용자 | 내 정보 조회·수정 | 변경 없음 | 동작 |
| 아이 | 목록·생성·수정 | 삭제 | 동작 |
| 도서 | 목록·상세 | 학습 표현 수 연결 | 동작 |
| 업로드 | multipart 직접 업로드 | 2단계 업로드 세션 | 동작 |
| 분석 | 작업 생성·상태 조회 | 결과 조회·취소 | 로컬 분석기 동작 |
| 표현 | 분석 결과 저장 | 상세 조회 | 동작 |
| 북마크 | 없음 | 저장·해제·필터 조회 | 동작 |
| 학습 이벤트 | 없음 | 멱등 저장·상태 갱신 | 동작 |
| 문장 연습 | 없음 | 저장·조회·규칙 첨삭 | 로컬 규칙 동작 |
| 대화 | 없음 | 시작·메시지·종료·조회 | 로컬 응답 동작 |
| 복습 | 없음 | 일정·답안·학습 요약 | 동작 |
| 알림 | 없음 | 설정·기기 등록 | 발송 연동 필요 |
| 음성 | 없음 | TTS/STT 계약 | 공급자 연동 필요 |

현재 사용자용 핵심 흐름은 API와 DB 수준에서 연결되어 있다. 외부 공급자와 운영자 도구는 별도 후속 작업이다.
