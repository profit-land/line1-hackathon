# 그림책 표현 학습 와이어프레임

다문화가정 외국인 부모가 한국어 그림책 속 표현을 아이와 함께 익히도록 돕는 서비스의 화면 와이어프레임.
디자인 코랩(이 저장소의 `design-collab` 앱) 프로젝트 "와이어프레임"에서 만들었고, 실제 데이터는 그 앱이 쓰는
Supabase DB의 `pages` 테이블에 있다. 이 폴더는 그 내용을 깃으로도 남기기 위한 스냅샷이다.

## 폴더 구성

- `generate_wireframe.py` — 화면을 정의하는 소스. 로컬로 뜬 디자인 코랩 서버(`http://localhost:5002`)의
  "와이어프레임" 프로젝트(id 3)에 있는, **이미 존재하는 페이지만** PUT으로 갱신한다. 사용자가 사이드바에서
  직접 지운 화면은 되살리지 않는다 — 새 화면을 추가하려면 먼저 디자인 코랩에서 빈 페이지를 만들어야 한다.
  ```bash
  cd design-collab
  python wireframe/generate_wireframe.py --dry   # 미리보기만 (실제 반영 안 함)
  python wireframe/generate_wireframe.py         # 서버에 반영
  ```
- `export_screens.py` — 지금 서버에 있는 화면들을 `screens/*.html`로 내보낸다.
  ```bash
  python wireframe/export_screens.py
  ```
- `screens/` — 내보낸 정적 스냅샷. `index.html`부터 열면 전체 목록이 보인다. 각 파일은 모든 화면을
  하나로 묶은 완전한 HTML 문서라 **서버나 디자인 코랩 없이 이 파일 하나만 더블클릭해서 열어도** 버튼이
  실제로 클릭되는 프로토타입으로 동작한다(스크립트 없이 CSS만으로 화면 전환).

## 화면 구성

A(시작) → B(홈) → C(단어 탐색) → D(단어 학습) → E(문장 연습) → F(대화 연습) → G(복습) → H(내 정보).
각 화면 오른쪽 노트에 목적·진입·이동·상태/예외가 적혀 있다.

## 참고

- 스냅샷을 다시 뜨려면 서버가 켜진 상태에서 `export_screens.py`를 다시 실행하면 된다(덮어씀).
- 서비스명은 아직 미정이라 화면에 "(서비스명 미정)"으로 표시된다.
